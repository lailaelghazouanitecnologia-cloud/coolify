# Legacy - Coolify PHP/Laravel

This directory is reserved for the original Coolify implementation built with:

- **Backend**: Laravel 12.4.1 (PHP 8.4.7)
- **Frontend**: Livewire 3.5.20 + Alpine.js + Tailwind CSS
- **Database**: PostgreSQL 15
- **Cache/Queue**: Redis 7

The current codebase in the project root will eventually be migrated here as we transition to the new Rust-based architecture in `kornetti/`.
